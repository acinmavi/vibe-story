Use after the user approves chapter 001. Arc 001 is preplanned as 30 chapters; chapter 001 exists already. You may **revise arc beats** with explicit explanation, but keep sealed logic coherent, respect user-approved chapter 001, and avoid writing chapter 002 until the approval gate is open.

## Phase 1: Approval to draft

1. Read user's exact approval. Update `approvals/approval.json` (status approved, evidence, UTC timestamp, project phase arc1_writing) and `continuity/story-state.json`.
2. Check for changes in `chapters/001.md` since reader approved. Do not alter approved text without permission.
3. Plan a batch of 2–4 chapters using the beat map, clue ledger, character-knowledge and unresolved plot loops.
4. For every chapter: outline scenes and knowledge boundaries, draft, reviewer pass, update state and canon, run validator, commit using a descriptive message.
5. If context budget or user interaction stops the process, commit completed checked chapters, report exactly where to resume. Don't claim background execution or completion without files.

## Arc acceptance

- 20–50 chapters; for arc 001 exactly 30 unless user directs otherwise.
- Each 3–5 chapter window changes either evidence, allegiance, stakes or interpretation; never 3 chapters of filler.
- One clean closure: explain the main puzzle, pay its cost, resolve selected emotional question, retain a **bounded** world-level hook.
- Reveal primary solution only after its required clues; false hypotheses tested, not arbitrarily discarded.
- After final chapter, produce reader-facing arc recap and author-only continuity dossier.
- Keep an arc fingerprint: locale type, core mechanism, moral dilemma, adversary strategy, victory method, cost, emotional change, final reveal. Compare to every earlier arc before developing arc N+1.

## Recommended checkpoints

Ch 1: anomaly, job competence, hook. Ch 2–5: entry/constraints, first evidence. Ch 6–10: competing hypotheses + trust conflict. Ch 11–15: failed test, high cost, mid-reveal. Ch 16–21: change plans, surviving evidence, reverse perspective. Ch 22–27: solution experiments, competing agency, irreversible choice. Ch 28–30: causal reveal, price, arc closure, world-level question.

Do not mechanically force this cadence into future arcs; vary genre, location and structure.
