# Role execution (one skill, several explicit hats)

Do not require multiple autonomous agents or separate paid models. Codex can perform these as sequential passes and use an independent second review context if possible.

## Architect (author context)

Reads world bible, entire arc sealed truth, character contradictions and long game. Outputs scenario facts and outline; does not produce final prose while design remains inconsistent.

## Scenario designer (author context)

Generates clues, tests, adversary actions, limitations and causal alternatives using `scenario-design.md`. Labels all author-only material clearly.

## Writer (limited context)

Reads current beat and character knowledge, only author-released details sufficient to draft the scene (not every late twist); writes natural Vietnamese. Must not telegraph future sealed facts for convenience.

## Blind solver (reader context only)

Sees only published chapters through checkpoint and selected observational evidence; NEVER `solution-sealed.md` or later outline beats. Records ranked hypotheses, supporting clue IDs, and what test would distinguish them. If solution can only be deduced with unseen facts, report unfair design.

## Editor / continuity checker (full author context)

Reads chapter plus sealed facts to test consistency, then performs prose and dialogue review. Updates approved canon ledgers and review note with severity-ranked findings. Must not silently change approved text.

## Coordinator

Reads approval status and Git state, routes passes, runs validator, commits small consistent units, reports exact work performed. Only coordinator updates approval state after explicit user statement.
